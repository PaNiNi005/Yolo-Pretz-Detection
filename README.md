โปรเจกต์ตรวจจับวัตถุ (Object Detection) สำหรับการตรวจจับกล่องขนม Pretz โดยใช้สถาปัตยกรรมโมเดล YOLO โปรเจกต์นี้ครอบคลุมตั้งแต่การเตรียมข้อมูล, การเทรนโมเดล, ไปจนถึงการทดสอบผลลัพธ์ผ่านรูปภาพ วิดีโอ และกล้องแบบเรียลไทม์

## 📁 โครงสร้างไฟล์ในโปรเจกต์ (Project Structure)

โปรเจกต์นี้แบ่งการทำงานออกเป็นสคริปต์ตามลำดับขั้นตอน ดังนี้:

* `01-export_dataset.py` - จัดเตรียมและส่งออกชุดข้อมูล (Dataset) สำหรับพร้อมเทรน
* `02-train.py` - สคริปต์สำหรับเริ่มเทรนโมเดล YOLO ด้วยข้อมูลที่เตรียมไว้
* `03-test_image.py` - ทดสอบโมเดลที่เทรนเสร็จแล้วกับไฟล์รูปภาพ (.jpg, .png)
* `04-test_video.py` - ทดสอบโมเดลกับไฟล์วิดีโอ (.mp4)
* `05-test-camera.py` - ทดสอบโมเดลแบบเรียลไทม์ผ่านกล้องเว็บแคม
* `data.yml` - ไฟล์คอนฟิกสำหรับกำหนดที่อยู่ของ Dataset และจำนวนคลาสเป้าหมาย
